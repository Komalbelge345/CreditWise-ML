# CreditWise ML – Loan Approval Prediction System

An end-to-end supervised machine learning project that predicts whether a loan application should be approved or rejected.

## Project Overview

CreditWise ML implements a complete machine learning pipeline for binary loan approval prediction. The project includes exploratory data analysis, data preprocessing, feature engineering, model training, and model evaluation.

Multiple classification algorithms were trained and compared to identify the best-performing model.

## Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
- Machine Learning
- Supervised Learning

## Machine Learning Algorithms

The following classification algorithms were implemented:

- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes
